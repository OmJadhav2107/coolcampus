# CoolCampus — Campus Heat & Shade Explorer
A beginner-friendly environmental mini-project that records observed heat levels, shade, surface type, optional measured temperature, and notes at campus locations.

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Try adding observations, filters, suggestions, remove, and reset.
4. Data persists only in the current browser via localStorage.

## Implemented in this prototype
- Add and remove location observations
- Record surface type, shade level, observed heat level, time, optional measured temperature, and notes
- Search and filter by heat/shade
- Summary counts and a simple priority insight for high-heat/no-shade locations
- Contextual suggestions for possible shade/greening interventions
- Browser-local persistence and sample-data reset
- Responsive layout

## Not implemented / future scope
- GPS/map integration, sensor integration, cloud database, multi-user sharing, login/admin, validated heat-index calculations, route recommendations, official campus approval workflow.
- The heat category is a user-entered observation, not a scientific risk model. Do not invent temperature readings. The sample records are demo data.
